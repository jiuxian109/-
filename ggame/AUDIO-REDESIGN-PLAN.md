## 0. 设计总纲

**一句话**：*声音是落在留白上的墨点——纸是底（静默），墨是层级（浓淡 = 响度与亮度），朱砂是唯一的行动声（落印），木与石是世界材质（木鱼与磬）。*

**三个形容词**（与视觉「纸 / 墨 / 朱砂 / 石绿 / 赭木、留白、运笔」同源）：

| 形容词 | 听觉对应 |
|---|---|
| **留白** | 无 BGM，静默是默认态；事件之间有空隙，长音衰减到无声 |
| **运笔** | 起音快、收尾慢（快attack慢release）；无果冻回弹、无硬切 |
| **落印** | 一击压实、不抖不弹：短促、干、一次性的「嗒 + 磬」组合 |

**与视觉 token 的同源映射**（声音也遵守「一色一义」）：

| 视觉 token | 声音语义 | 材质原语 |
|---|---|---|
| `--paper`（纸） | 底噪 / 氛围级 | 纸墨（滤波噪声） |
| `--ink`（墨，五阶） | 层级浓淡 | 响度 + 亮度分级，同一材质不换乐器 |
| `--seal`（朱砂，唯一强调） | 唯一行动声 | 落印（木「嗒」+ 磬 bloom） |
| `--jade`（石绿，世界材质） | 石 / 岛 | 磬（石钟） |
| `--wood`（赭木，世界材质） | 木块 / 木鱼 | 木鱼（共振木敲击） |
| 留白 | 静默 | 静默是素材，不是缺口 |

## 1. 声音身份与材质谱系（全合成原语）

全部复用并扩展现有 `tone / thud / pluck / bell` 思路，但不引入任何音频文件。**不加混响**——水墨是「近距离、干、纸上的墨」，磬靠自身长尾提供空间感，dry 也更省 CPU、更贴零文件约束。

| 原语 | 合成法 | 参数方向 | 语义 |
|---|---|---|---|
| **磬**（石钟） | 正弦基频 + 非整数倍泛音（2.76×、5.4×），指数衰减，长尾 0.8–1.5s，软起音 5ms，轻微 detune 制造「晕」 | 基频、尾长、亮度 | 石 / 岛 / 胜利 / 星级 / 解锁 / 落印高音 |
| **木鱼**（木敲击） | 共振带通噪声（Q 2–4）+ 低频正弦体（180–300 Hz），极短衰减 0.04–0.15s | 中心频率、Q、时长 | 木块 / 撞击 / UI 木点 |
| **拨弦**（皮筋 / 弦） | 三角/正弦快速下滑 + 短噪声「啪」 | 起频、落频、下滑时长 | 出手、取消回弹 |
| **皮筋拉伸**（弓弦张力） | 谐振带通噪声（Q 6–9），中心频率随拉力上升 + 低正弦「弦基频」 | 中心频率、Q、增益 | 拉弓（常驻，门控） |
| **纸墨**（纸 / 墨） | 滤波噪声：运笔 = 高通 3kHz 短涌；墨点 = 极短低通噪声轻点；翻页 = 带通 2kHz 80–120ms 涌 | 滤波类型、中心频率、时长 | UI 点击、切换、落地（闷）、氛围 |
| **落印**（印章，签名动作） | 木鱼「嗒」+ 延迟 15ms 的磬，磬经低通「洇开」（bloom：低通从 500→4000Hz 开 0.12s），单次、无音高弯、无回弹 | 嗒频率、磬频率、bloom 时长 | 主按钮、胜利收尾、解锁、得分确认 |
| **洇开**（失败，墨散） | 噪声床低通 2000→300Hz 关 0.6s + 慢正弦下滑 220→147Hz，安静 | 低通终点、下滑时长 | 失败 |

> 关键决定：**响度与亮度 = 墨的浓淡，不是换乐器**。次要动作是「淡墨点」（暗、轻、木鱼单打），主要动作是「朱砂落印」（亮、略重、木鱼 + 磬）。层级靠同一材质的两档，不靠第二套音色。

## 2. 交互点逐项设计

> 标「现状」为 `game.js` 现有实现；「重做」为本方案。响度用 `L0–L4` 分层（定义见 §4）。频率默认以宫调 C 五声（宫 C 261.6 / 商 D 293.7 / 角 E 329.6 / 徵 G 392 / 羽 A 440）为参考系。

### A. 拉弓（`state==='dragging'`，`pullStart/pullUpdate/pullStop`，game.js:620/451/656）

- **现状**：常驻锯齿经带通（Q7），频率 90+230t、增益 0.015+0.035t。锯齿是「电子/塑料」质，与水墨冲突。
- **重做**：**皮筋拉伸原语**，两件叠：
  1. 谐振带通噪声（「纤维绷紧」）：中心 220→800Hz（随 `t = pull/MAX_DRAG`），Q 8，增益 0.010+0.030t。
  2. 弦基频：正弦 82+40t Hz，增益 0.012（弦被拉紧后音高微升）。
  3. 接近满弦（t>0.85）叠加 8Hz、深度 0.2 的轻微幅度颤音（AM），暗示「极限」。
- **时长**：常驻（按住期间），松手即停。
- **响度**：L1（最安静的持续声，是「紧张」不是「噪音」）。
- **新增**：越过 `MIN_PULL` 死区线（game.js:153）的瞬间，补一记**墨点「嗒」**（木鱼 900Hz / 0.03s / gain 0.05）——与力度条「青绿→朱砂」变色同步，听觉确认「现在松手会发射」。这是当前缺失交互（见 §7 第 3 条）。

### B. 出手（`sLaunch`，game.js:650）

- **现状**：`pluck(680,150,0.22,0.16)`，无力度参数。
- **重做**：**拨弦 + 破空**，按出手力度 `f = maxPull/MAX_DRAG` 分级：
  1. 皮筋「啪」：高通噪声 2500Hz / 0.04s / gain 0.05+0.05f。
  2. 弦振「嘣」：三角波 620+180f → 160Hz 下滑 0.18s / gain 0.10+0.06f。
  3. 破空「嗖」（可选，仅满弦时更明显）：带通噪声 1200Hz / 0.25s 涌 / gain 0.03+0.03f。
- **时长**：≈0.25s。
- **响度**：L3（出手是全流程最「实」的一下）。
- **要求**：给 `sLaunch` 加力度入参；`maxPull`（game.js:156）在 `fireBird` 时仍可读，用它驱动 `f`。

### C. 飞行中（`state==='flying'`，无现音）

- **决策**：**不做连续飞行声**。飞行段的静默就是「留白」，它让随后的撞击落得更重；紧张感由「拉弓的持续低鸣 → 出手一瞬 → 静默」的对比完成，这本身就是没有 BGM 时的「音乐弧线」。
- 破空声已在出手（B-3）里一次性给足，不另起循环。

### D. 撞击木块（`sHit(k)`，game.js:417，collisionStart 内 `vn>3` 时）

- **现状**：60ms 节流，`thud(0.05+0.15s, 420+620s, 0.08+0.10s)`。
- **重做**：**木鱼单打**，按撞击强度 `k = min(1, vn/16)` 分级：
  - 木鱼体：带通噪声中心 500+400k Hz / Q 3 / 0.06+0.08k s / gain 0.06+0.12k。
  - 木体低频：正弦 180+120k Hz / 0.08s / gain 0.05+0.08k。
  - 硬撞击（k>0.7）追加「裂」：高通噪声 2kHz / 0.03s / gain 0.04。
- **时长**：0.06–0.14s。
- **响度**：L2（软击）→ L3（硬击）。
- **节流**：50ms（保留并略收紧现有 60ms）。

### E. 木块被击倒 / 判定成立（`sClear`，game.js:485，`fell||tilted||moved` 时）

- **现状**：`thud(0.15,1200,0.13) + tone(150,0.10,'square',0.06,0,70)`。square 150→70 是「游戏音效 blip」，且与 `sHit` 同时触发会叠噪。
- **重做**：**「倒」= 木鱼双敲 + 磬确认**，与撞击（D）形成「低撞击 → 高确认」的两层，不再冗余：
  1. 木鱼双敲「嗒-嗒」：中心 800Hz / Q 3 / 各 0.07s，间隔 40ms。
  2. 磬确认：角 E5 659.3Hz（或徵 G5 784Hz，两关轮换免单调）/ 尾 0.3s / gain 0.05。
- **时长**：≈0.35s。
- **响度**：L2，但**相对撞击晚 40ms 起**，避免掩蔽撞击。
- **节流 + 合并**：80ms 内多个木块同时判定，只播一次、改用双敲并微提增益（「连倒」一次结清），防 5 块同帧叠噪。

### F. 奶龙落地 / 滚动（无现音，MISSING）

- **现状**：`collisionStart` 只对 `A._block||B._block` 触发 `sHit`（game.js:417），奶龙砸岛/地面完全无声。
- **重做**：**纸墨闷响**（比木鱼更软、更「肉」，贴合奶龙角色）：低通噪声 300→100Hz / 0.12s / gain 0.07 + 低正弦 90Hz / 0.1s / gain 0.05。
- **时长**：≈0.12s。
- **响度**：L1–L2（比木块轻，突出「软」）。
- **节流**：80ms（滚动时的连击合并）。

### G. 取消发射 / 回弹归位（`sReturn`，game.js:666，`pull<MIN_PULL`）

- **现状**：`pluck(220,110,0.16,0.07)`。
- **重做**：**皮筋松弛**——拨弦下滑 220→110Hz / 0.15s / gain 0.05 + 极轻纸墨「簌」（高通噪声 3kHz / 0.06s / gain 0.02）。
- **时长**：≈0.15s。
- **响度**：L1（这是「没发生」，要轻）。

### H. 弹弓左右平移（`state==='movingSling'`，无现音，MISSING）

- **现状**：平移完全无声，松手用 `sClick`（game.js:654）。
- **重做**：**导轨滑动摩擦**——常驻节点：噪声 → 低通 400Hz + 带通 180Hz 颗粒感 / gain 0.02，`movingSling` 期间门控开启，松手即停。极轻，是「木轴在纸上磨」的底噪。
- **响度**：L0（几乎不可闻，仅提供位移触感）。
- **性能**：与拉弓同策略——一个常驻节点复用，不逐帧建新节点。

### I. UI 点击（`sClick`，全部 19 处调用点）

- **现状**：`tone(880,0.05,'triangle') + thud(0.05,2200,0.04)`——880Hz「哔」是通用系统音。
- **重做**：**墨点原语**，按按钮层级分两档：
  1. **淡墨点**（次要/幽灵：选关、返回、关闭、全屏、弹弓平移松手）——木鱼体 850Hz / Q2.5 / 0.04s / gain 0.06，纯木。
  2. **朱砂落印·轻**（主按钮：开始/继续、下一关、再来一次、重来、从头开始、通关视频内按钮）——淡墨点 + 延迟 15ms 的磬 1318.5Hz / 0.12s / gain 0.04。
- **时长**：0.04–0.15s。
- **响度**：L1（次）/ L2（主）。
- **实现建议**：拆成 `sClick(soft)` 与 `sClickPrimary()` 两个语义函数，替代现在的单一 `sClick`，调用点按上表分派。

### J. 静音切换（`muted`，game.js:596–600 / 1577–1580）

- **现状**：静音 = 立即停拉弓声；开音 = `sClick`。
- **重做**：**静音时不出声**（图标切换本身即反馈，正确保留）；**开音时**用「淡墨点」而非主按钮落印，避免「恢复声音」和「主动作」抢响度。行为不变，只把开音从 `sClickPrimary` 降为 `sClick(soft)`。

### K. 胜利（`sWin`，game.js:1397，`doWin`）

- **现状**：`bell` C-E-G-C（523/659/784/1046）大调琶音——西式竖琴琶音，且无星级声、无收尾。
- **重做**：**磬五声 + 星级 stagger + 落印收尾**，把「通关印章落下」做成一个小三段：
  1. **通关短语**（宫调，留白间隔 110ms）：徵 G4 392 → 羽 A4 440 → 宫 C5 523.25，各尾 0.5s，gain 0.16。
  2. **星级三声**（严格对齐 `renderStars` 的 `animation-delay: 0.34+i*0.13`，game.js:1389）：角 E5 659.3 → 徵 G5 784 → 宫 C6 1046.5，各尾 0.3s，gain 0.07，逐星 stagger。
  3. **落印收尾**（≈0.85s 处）：单次压实（§1 落印原语，木鱼 300Hz「嗒」+ 磬 C6 1046.5 bloom），gain 0.14。
- **时长**：≈1.3s。
- **响度**：L4（全流程最高，但只此一次、不循环）。

### L. 失败（`sLose`，game.js:1417，`doLose`）

- **现状**：`tone 300→150 + tone 196→110 + thud`——下滑正弦是「答错蜂鸣」感。
- **重做**：**洇开原语**（对齐视觉 `sealBleed` 的「朱砂从纸背洇出、不动不晃」）：
  - 噪声床低通 2000→300Hz 关 0.6s / gain 0.05。
  - 慢正弦下滑 220→147Hz（A3→D3）/ 0.6s / gain 0.06。
  - 起手一记低木鱼 220Hz / 0.07s / gain 0.07。
- **时长**：≈0.7s，收于静默（失败的「留白」）。
- **响度**：L2–L3（比胜利低一档，安静、不聒噪）。

### M. 过关面板 / 视频小窗出现（`doWin` 后半，`showVideo`，无现音，MISSING）

- **重做**：**落印**（单次压实）：木鱼 300Hz「嗒」+ 磬 C6 1046.5 bloom / gain 0.13。与 §K 的收尾落印合并为一次（胜利短语 + 面板落印不要连打两次）。
- 视频小窗（`showVideo`，game.js:1420）打开时同用一记落印；视频自带音轨正常播放，游戏侧不再叠音。
- `playHint`「点击播放」（game.js:1525）补一记淡墨点。

### N. 关卡切换 / 重建 / 重开（`buildLevel`、`startLevel`、`restart`，无现音，MISSING）

- **重做**：**翻页/展纸**——带通噪声 1800Hz / 100ms 涌 / gain 0.03 + 一记极轻木鱼 500Hz / 0.05s / gain 0.04。
- **响度**：L0–L1（场景底噪，不抢操作声）。
- **首次解锁新关卡**（`progress.cleared` 从 false→true，选关卡锁 icon 变为星）补一记**锁开**：木鱼 tick + 磬 C6 1046.5 / 0.2s / gain 0.06，只在「本轮第一次解锁」播一次。

### O. 竖屏提示 / 仍要竖屏玩（`rotateOverlay` / `portraitPlay`，game.js:1604）

- **现状**：`portraitPlay` 已有 `sClick`。
- **重做**：`rotateOverlay` 自动出现时**保持静默**（避免每次转屏都打扰）；「仍要竖屏玩」改派 `sClickPrimary`（这是一个明确的用户决定）。

## 3. 整体节奏与留白策略

1. **静默是底、墨点是字**：无 BGM，默认零声。一次操作一声，不铺氛围循环。
2. **动静对比即音乐弧线**：拉弓（持续低鸣、渐紧）→ 出手（一瞬）→ 飞行（静默）→ 撞击（短促）→ 归静。紧张与释放的对比替代了背景音乐的推进。
3. **一拍一点，最多三声叠**：除碰撞瀑布（cascade）外，任何时刻同时发声 ≤3。击倒连倒用「合并单次 + 双敲」结清，不逐块播。
4. **呼吸点**：静止判定 `settleTime>400ms`（game.js:526）+ `evaluate` 前的 140ms 延迟，保持静默，作为自然的「换气」；新奶龙就位（`spawnBird`）不配音，静默就是「准备好了」。
5. **运笔式包络**：所有一次性音效统一「快 attack（≤5ms）、指数慢 release」，无硬切、无回弹（与 `--ease` `cubic-bezier(.22,.61,.36,1)` 同源）；只有「落印」是快攻快收的压实，无尾音弯。
6. **衰减分级给留白**：磬尾 0.3–1.5s、木鱼 0.04–0.15s、纸墨 0.06–0.25s——长尾的只有「世界材质（石）」与「朱砂确认」，短尾的归「墨点」，层级靠尾长再分一档。

## 4. 响度分层与混音总线

**建议把现在「直连 destination」改为一条极简总线**（仍全合成，无文件）：`全部声源 → masterGain → DynamicsCompressor → destination`。Compressor 作安全限幅（阈值 −12dB、比 4:1、knee 12、attack 3ms、release 250ms），防碰撞瀑布削波。

**响度阶梯**（相对增益，现有代码绝对值 0.02–0.22 可映射到该阶梯）：

| 层 | 相对增益 | 内容 |
|---|---|---|
| L0 底噪 | 0.02–0.04 | 弹弓平移摩擦、翻页、飞行破空 |
| L1 触感 | 0.05–0.08 | 次要点击、取消回弹、奶龙软着陆、拉弓底鸣 |
| L2 反馈 | 0.09–0.13 | 主按钮落印、木块软击、击倒确认、星级 |
| L3 事件 | 0.14–0.18 | 出手、硬击、落印收尾 |
| L4 重音 | 0.18–0.24 | 胜利短语（唯一 L4，且只一次） |

**层级不换乐器**：浓墨（主动作）用 L2–L3 + 磬高音；淡墨（次动作）用 L0–L1 + 纯木鱼/纸墨。亮度与响度同向涨跌。

## 5. 静音与暂停处理

1. **静音**：`muted` 保持唯一真源。静音 = masterGain 在 50ms 内 ramp 到 0 + 立即 `pullStop()`（现有 game.js:598/1579 已做拉弓停止，保留）；开音 = ramp 回 1 + `ensureAudio()` + 淡墨点确认。
2. **暂停**：游戏无显式暂停，但需兜底：`visibilitychange` 或 `audioCtx.state==='suspended'` 时，下一次用户手势（`pointerdown` 已调 `ensureAudio`，game.js:168）自动 `resume()`；恢复后不补播任何历史音。
3. **状态切换**：进 `flying/settled/won/lost` 时强制 `pullStop()`，杜绝残留拉弓声；`restart/startLevel` 时清掉所有常驻节点（拉弓、平移摩擦）。
4. **降级**：`prefers-reduced-motion: reduce` 时只保留必要反馈（点击 / 出手 / 撞击 / 胜负），去掉装饰性破空、翻页、星级 stagger、拉弓颤音。

## 6. 性能与节流

**发声数预算**（WebAudio 合成，瓶颈是同时衰减中的节点数，不是内存）：

| 平台 | 并发一次性声源上限 | 常驻节点（拉弓 / 平移摩擦） |
|---|---|---|
| 桌面 | 32 | ≤2 |
| 移动 | 20 | ≤2 |

**节流与合并表**：

| 事件 | 策略 |
|---|---|
| 撞击 `sHit` | 50ms 节流（收紧现有 60ms） |
| 击倒 `sClear` | 80ms 合并；同帧多块 → 单次双敲 + 微提增益 |
| 奶龙落地 | 80ms 节流（滚动合并） |
| UI 点击 | 用户节奏，不节流 |
| 星级三声 | 按 `renderStars` stagger 预排程，不节流 |

**结构约束**：
- 噪声缓冲保持单条共享（现有 0.4s，够用；破空/翻页最长达 0.25s，无需加长）。
- 常驻节点复用（拉弓、平移摩擦），`pullUpdate` 只对已有节点 `setTargetAtTime`，`update()` 循环内不建任何新节点；一次性音效全部事件驱动。
- 磬 / 木鱼 / 纸墨 / 落印由 §1 原语函数复用，同一原语同帧多次调用共享参数路径，避免重复建滤波链。
- CPU 预算：音频 DSP 每帧 < 0.5ms（最低目标硬件上测），远低于 Matter 物理；真正的成本控制点是「并发衰减节点 ≤ 上限」+「节流」。

## 9. 实施顺序建议（三轮）

| 轮次 | 内容 | 判据 |
|---|---|---|
| 第一轮（原语 + 核心动词） | 重建 §1 七原语；重做拉弓 / 出手 / 撞击 / 击倒 / 取消 / 落地；补死区 tick | 核心手感音不再有锯齿 / square / 三角哔；拉弓到撞击的动静弧线成立 |
| 第二轮（UI + 胜负 + 系统） | 重做点击两档 / 静音 / 胜利三段 / 失败洇开；补翻页、落印、锁开、星级 stagger | 全部 `s*` 调用点换装完毕；胜负与「落印/洇开」视觉签名同步 |
| 第三轮（收口） | 总线 + compressor + 节流/合并 + `prefers-reduced-motion` 降级 + 真机发声数压测 | 最低目标硬件碰撞瀑布下 0 削波、0 卡顿；并发节点 ≤ 预算 |

## D.2 新音频图
`ensureAudio()` → `noiseBuf`(1.0s) + `master: GainNode` → `DynamicsCompressor(threshold -12, ratio 4, knee 12, attack 0.003, release 0.25)` → destination。
所有原语经 `out()` 取 `master || audioCtx.destination`，因此静音只需动一个节点。
七原语 `tone` / `thud` / `snap` / `swish` / `bell` / `wood` / `pluck`，加 `seal`（签名落印）与 `bleed`（洇开）。
