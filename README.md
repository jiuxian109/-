## 玩法

木块**没有血条** —— 被撞得掉下岛、翻倒（超过约 40°）或横向挪位超过 45px 就算「**击倒**」，
把一关的木块全部击倒即通关。每关给定奶龙发数。

**星级只看「通关时还剩几发」** —— 每关的阈值写在自己的数据里（`levels.js` 的 `stars`），
四关目前都是「剩 ≥ 2 发 = ★★★、剩 1 发 = ★★、刚好用完 = ★」。
通关至少要打一发，所以**通关必得至少一星**；一局里剩下的发数越少，说明你越早找到那一杆。

| 关卡 | 名称 | 奶龙 | 木块 | 浮空岛 | 实测最少发数 | ★★★ 条件 | 离线实测 ★★★ 达成率 |
|---|---|---|---|---|---|---|---|
| 1 | 云间初试 | 6 | 8 | 3 座 | 2 | 剩 ≥ 2 发（≤ 4 发通关） | 36.3% |
| 2 | 叠叠高 | 6 | 9 | 3 座 | 2 | 剩 ≥ 2 发（≤ 4 发通关） | 44.2% |
| 3 | 一柱擎天 | 6 | 10 | 3 座 | 2 | 剩 ≥ 2 发（≤ 4 发通关） | 41.0% |
| 4 | 巅峰论道 | 7 | 11 | 4 座 | 2 | 剩 ≥ 2 发（≤ 5 发通关） | 38.6% |

> **表里所有数字都来自离线仿真，不是真人试玩**：
> 「实测最少发数」＝真 Matter 引擎离线束搜索（`node editor/run-search.mjs 1 2 3 4`）；
> 「★★★ 达成率」＝离线随机放样 8000 条路线里、通关路线中能拿三星的比例
> （`node editor/run-sample.mjs 1 2 3 4 --n 8000`）。随机放样每发都从全部候选拉法里随机挑，
> 所以它给出的是**下限**：会玩的人挑角度、还能左右挪弹弓（离线网格固定在 x=185），真实达成率只会更高。
> 真人试玩数据目前**一条都没有**。
>
> 全部四关重画的完整依据（坐标表、难度校准、阈值推导、两个保真度缺陷的复盘、
> 未验证项清单）见 [`ggame/LEVEL-REDESIGN-PLAN.md`](ggame/LEVEL-REDESIGN-PLAN.md)。

### 特殊木块

关卡里会出现两种带标记的木块。**它们与星级无关**（星级只看剩余发数），只是打法变化：

| 木块 | 外观 | 规则 | 音效 |
|---|---|---|---|
| **护心块** | 赭木上叠一圈墨色木鱼纹 | 被其他木块连锁撞到时**完全不生效**，只有奶龙直击才算 | 被连锁撞击时**静音**；被直击倒下时是**更闷更低的木鱼声** |
| **落印块** | 赭木上盖一枚朱砂印 | 必须真的被**压平或掀翻**（掉 30px / 倾角 > 0.5rad）；单靠平推挪位不算，印还没落 | 倒下时响**落印音**（木鱼 + 磬的余韵） |

**第 1 关就是这两种块的教学关**：三座岛排成三站课 ——
普通三层塔（教基本发射与「打底不打顶」）→ 连锁源 + 护心块（教「连锁撞不倒，只认奶龙直击」）
→ 独坐的落印块（教「必须真的压平或掀翻，单靠平推不算」）。
教到哪一站就弹一张提示卡，**卡片出现时整个游戏暂停**（物理、计时、画布输入全冻结），
玩家点「知道了」才继续；同一张卡一局只出一次，点「重来」不会重放。
触发时机写在第 1 关的 `teach` 数组里（`start` 开局 / `shot1` 第一发后 /
`protectTouch` 护心块被碰过 / `sealTouch` 落印块被碰过）。


## 操作

| 操作 | 效果 |
|---|---|
| 拖动奶龙往后拉 → 松手 | 发射。拉得越满越远，松手前会显示**弹道预演虚线**和**力度箭头** |
| 拉不到 30px 就松手 | **取消发射**，奶龙弹回皮兜，不扣发数 |
| 拖动**弹弓的叉尖或手柄** | 弹弓在发射台上**左右平移**（奶龙跟着皮兜走） |
| 开始界面「☰ 选关」 | 打开选关面板（关卡名 / 奶龙 / 木块 / 星级）。**通关一关才解锁下一关** |
| 右上角 🔊 / 🔇 | 静音开关 |
| 右上角 ⛶ / 开始界面的「⛶ 全屏」 | 切换浏览器全屏 |
| 手机上 | 画布右上角那三个小芯片换成页面上的大按钮；竖屏自动提示「请把手机横过来」 |

## 选关与进度

开始界面的「☰ 选关」打开选关面板，四张卡片各写关卡名、奶龙数、木块数与本关成绩。

- **渐进解锁**：第 1 关永远开着，之后每关都要先通关前一关；未解锁的卡片变灰、带 🔒、点不动
- **进度写 localStorage**（键 `ddd.progress.v1`，只存 `cleared` 与最好 `stars`）—— 关掉浏览器再打开还在。隐私模式或被禁用 localStorage 时静默降级为只在内存里记
- **开始界面的主按钮**在有进度时会明写「▶ 继续第 N 关」，指向哪一关不藏着

## 手机上玩

- **横屏**：游戏是 16:9 的，手机竖屏时会盖一层「请把手机横过来」的提示层（横过来自动消失）
- **竖屏也能玩**：那层提示下面有「仍要竖屏玩」，点了之后画面贴顶铺满宽度，画面下方那一大块留白变成操作区（关卡 / 发数 / 得分信息条 + 底部 56×56 大按钮）。**这个竖屏选择本身不写 localStorage**，转回横屏再转回竖屏会重新问一次（关卡进度是另外存的，见上一节）
- **按钮**：画布右上角的 ↻/🔊/⛶ 三个芯片在触屏上会换成页面上的大按钮（横屏 46×46、竖屏 56×56），发数等信息条自动挪到左侧一列
- **热区**：奶龙抓取半径、弹弓热区按「至少 52 CSS px」自动放大，HUD 芯片和字号也一起放大
- **全屏**：iOS Safari 不支持元素全屏（`requestFullscreen` 对 `<video>` 之外无效），检测到不支持时全屏按钮自动隐藏
- **手势**：禁掉了页面滚动、下拉刷新、双击缩放与长按弹出的系统菜单

## 怎么跑

纯静态，**不需要任何构建步骤、也没有网络依赖**（Matter.js 已内联在 `ggame/lib/` 里）。

```bash

```

## 调关卡

关卡数据全在 [`ggame/levels.js`](ggame/levels.js)，是个**纯数据文件** —— 改木块摆放不用动 `game.js`。

**图形化调（推荐）**：用浏览器打开 `editor/editor.html`

> `editor/` 是本地工具目录，已经写进 `.gitignore`，不进版本库；它直接读 `../ggame/levels.js`，所以两边数据始终是一份。

- 拖动木块移动 · 双击空白加块 · `Delete` 删块 · 方向键 1px 微调（`Shift` + 方向键 ×10）
- 默认**吸附**：自动吸到「岛面 / 岛中心 ± 44 栅格 / 上下叠层」，按住 `Shift` 拖动可临时关掉
- 拖岛改位置 · 改奶龙只数 · 一键「贴岛面」「吸到 44 列」
- 改动自动存在浏览器里（刷新不丢），点**复制关卡数据**，覆盖 `ggame/levels.js` 里那个数组即可
- 「复位本关 / 复位全部」回到 `ggame/levels.js` 里的版本

**手改**：直接改 [`ggame/levels.js`](ggame/levels.js) 里的数字。坐标规则写在文件顶部注释里，最要紧的两条：

- 木块 `x, y` 是**中心**坐标；岛 `top` 是**岛面**那条线
- 放到岛面上：`y = 岛.top − h/2`（44 高的块就是 `top − 22`）；往上叠一层 `y` 再减 44；左右并排 `x` 加 44

注意：改完摆放关卡难度就变了。**每次改完都必须跑离线验收**，别靠肉眼估：

```bash
node editor/verify-geom.mjs                       # 几何自检：重叠、悬空缝、越界岛、HUD 区侵入
node editor/check-align.mjs                       # 离线核心与 game.js 的判定阈值 / 链路是否还对得上
node editor/check-mechanics.mjs                   # 护心块「免疫连锁」、落印块「平推不算」的行为断言
node editor/run-search.mjs 1 2 3 4                # 真 Matter 引擎逐发穷举：最少发数 / 一发清台候选
node editor/run-sample.mjs 1 2 3 4 --n 8000       # 随机放样：通关率、发数分布、三星达成率
node editor/_cdp-e2e.mjs                          # 真浏览器端到端：教学卡弹出 / 暂停 / 输入冻结
node editor/gen-blueprints.mjs                    # 重画 course/blueprint-L1..L4.svg 四张图纸
```

**三星达成率是随发数额度变的**：三星 = 用掉 ≤ `birds − stars.three` 发通关，
所以改 `birds` 或 `stars` 就等于改难度，改完必须重跑 `run-sample.mjs` 确认仍落在 30–50%。

`editor/` 目录不进版本库（`.gitignore`），是本地校验工具；验收阈值见
[`ggame/LEVEL-REDESIGN-PLAN.md`](ggame/LEVEL-REDESIGN-PLAN.md) §5。

## 技术要点

- **物理**：[Matter.js](https://brm.io/matter-js/)，960×540 世界，`gravity.scale = 0.001`，固定 60Hz 步进。
  世界**没有地面也没有墙** —— 浮空岛是唯一的支撑体，没接住的东西会直接掉出画面。
- **水墨渲染全部用 canvas 手绘**，没有引入任何位图素材：宣纸底、朱砂太阳、三层淡墨远山、
  青绿山石浮空岛（苔草 / 苔点 / 垂藤）、赭木块、以及用变宽笔触画的墨笔弹弓 + 珊瑚红皮筋。
- **弹道预演与真实轨迹完全一致**：预演不是近似抛物线，而是照引擎的真实积分公式逐步推演
  （`gravity.y × gravity.scale × dt²`，并乘上 `frictionAir` 阻尼），与真实飞行路径偏差 `0.000px`。
- **下坠加重力**：奶龙一旦进入下坠（`vy > 0`）就额外施加 30% 重力，让高抛弧线「压」下来。
  刻意不去改 `engine.gravity` —— 那样木块会跟着一起变重。
- **撞击威力**：奶龙下坠中命中木块时补一份冲量（`IMPACT_BOOST = 2.0`），
  而且**只推木块、从不碰奶龙**，所以出手弧线与落点在开启前后完全一致。
- **音效全部是实时合成**的 WebAudio，没有音频文件：噪声音源 + 低通做木质闷响，
  扫频拨弦做发射，四音琶音做通关。
